# Third-party notices

## Bundled dependencies

Runtime and build dependencies are declared in `package.json` and their licences
travel with them in `node_modules`. This file covers work that influenced the
codebase without being bundled.

## Reference projects (no code included)

The Voyager Investment Intelligence Engine was designed after reading the
projects listed in `docs/investment-engine/THIRD_PARTY_REFERENCES.md`. No source
file from any of them is copied, adapted, or vendored into this repository, and
`docs/investment-engine/LICENSE_AUDIT.md` records the commit examined and the
licence found for each.

Included here so that a reader auditing the product can find that record without
knowing to look for it.
