them is a prompt this repository has already implemented.

## 2. Lessons — this prompt is already implemented

`Lessons_Redesign/CLAUDE_CODE_PROMPT.md` is the **original full-portal redesign
brief**, the one this session opened with: the `design_handoff` folder, the
seventeen mockups, the refinement layer that overrides them (no gradients, flat
`#2ee6a8`, monochrome icons, one mint action per screen). It was applied.

What is genuinely outstanding from it is the screens the redesign never reached,
which the session notes list: My TradingNew, My Money, Practice Portfolio,
Plans, Experts, News, Economy, ETF Detail, Supercharts. The Academy and Course
Detail mockups in that folder belong to that list.

So: not a new section. A named subset of an old backlog, and worth confirming
which screens are wanted rather than re-running a prompt whose output is
already shipped.

## 3. Events — visual layer only, and a pass has been done

`Events_Redesign/CLAUDE_CODE_PROMPT_EVENTS.md` opens by saying the logic is
written and must be kept — filters, three view modes, search, pagination,
analytics — and only the visual layer changes.

A visual pass landed earlier in this session: 16 cover gradients flattened, the
primary action moved off violet, the save control restyled. The prompt's own
list of what remains is the Calendar and Map views, which that pass did not
bring to the mockup.

## The order worth doing them in

1. **Events** — smallest, bounded, and the remaining part is two views.
2. **Tools & Data** — the real build, and the one that deserves a fresh start.
3. **Lessons** — confirm the screen list first; most of the prompt is done.
